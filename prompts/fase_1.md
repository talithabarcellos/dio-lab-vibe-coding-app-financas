Vamos começar pela **Fase 1 — Fundação** do PRD.

Antes de implementar, analise a estrutura necessária para o aplicativo e identifique as opções gratuitas disponíveis para autenticação, banco de dados e persistência.

Implemente apenas esta fase, incluindo:

- Estrutura inicial do projeto.
- Interface responsiva para computador e celular.
- Identidade visual e navegação principal.
- Tela de cadastro, login e saída da conta.
- Configuração do banco de dados persistente.
- Proteção dos dados para que cada usuário acesse somente seus próprios registros.
- Estrutura inicial das telas principais, sem simular funcionalidades que ainda não existem.

**Restrições importantes:**
- Priorize soluções gratuitas e informe se houver limites ou custos.
- Não implemente integrações bancárias, leitura de PDFs ou imagens.
- Não crie dados financeiros fictícios como se fossem reais.
- Não avance para as próximas fases antes de validar esta.
- Não exponha chaves secretas no frontend.

Ao terminar, informe o que foi implementado, quais serviços foram utilizados, se existe algum custo potencial e quais testes foram realizados. Se houver decisões importantes de arquitetura, explique-as antes de prosseguir.
